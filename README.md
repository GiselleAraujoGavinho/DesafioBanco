# 🏦 Desafio Banco

Este é um aplicativo simples desenvolvido em Java para simular o controle de uma conta bancária.

## 🎯 Objetivos do Projeto

O objetivo deste projeto é implementar um sistema simples de controle bancário, com as seguintes funcionalidades:

- Exibir os dados do cliente (Nome, Tipo da Conta e Saldo).
- Apresentar um menu de opções com 4 funcionalidades principais:
  - **Consultar saldo**: Exibe o saldo atual da conta.
  - **Transferir valor**: Permite transferir um valor para outra conta, com verificação de saldo.
  - **Receber valor**: Adiciona valores ao saldo da conta.
  - **Sair**: Finaliza a aplicação.
